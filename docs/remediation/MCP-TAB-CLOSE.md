# MCP 主动关闭 SSH 标签页

日期：2026-11-17。

新增工具 `close_mcp_ssh_tab`，输入仅为打开连接或命令执行结果中的不透明 `tab_ref`，成功返回 `status: closed`。打开与执行结果增补可选 `tab_ref`；已自动关闭的命令标签页不提供引用。

插件只登记 MCP 创建的实际标签对象，后续复用保持同一引用，按凭据 ID 与 generation 隔离；不枚举或按标题、profile_ref、原生标签 ID、窗口 ID 搜索其他标签。手动关闭后清理登记，服务停止时使引用失效，不自动关闭保留的标签。旧身份或旧引用不能用于关闭其他对象。

关闭不新增 SSH 命令审批，但仍要求有效的 MCP 客户端会话、请求期限及关闭前审计成功。关闭前再次检查取消和当前服务身份；并发关闭返回 busy。关闭后审计失败或身份失效返回 outcome_unknown。删除 SSH 白名单不妨碍当前有效客户端清理自己已创建的标签。

不自动重试未知结果，不提供关闭全部窗口、关闭用户手动标签、终止远程进程或列出整个 Tabby 标签页的接口。显式关闭 SSH 标签页可能中断未结束的远程进程；输出截断并不代表进程已经结束。

验证覆盖：客户端与 generation 隔离、手动销毁、重复/并发关闭、关闭取消、过期请求、审计失败、服务重启、打开/执行返回引用、自动关闭和自动关闭失败后的保留行为，以及真实 MCP HTTP 调用链。测试只使用隔离凭据和 SSH 标签替身，不操作私人配置或真实 SSH。

最终验证：542 项普通/脚本测试（IPC 59、Companion 142、插件 295、脚本 46）、5 项 HTTP 集成测试均通过；workspace 类型检查、Angular 严格模板检查、构建、pack check、`git diff --check` 均通过。独立复核未发现新增的已确认安全或生命周期问题。
