# SSH 命令审批模式：实现与验证

日期：2026-11-16。分支：`codex/command-approval-modes`，基于 `dev@b172cc9`。本轮修改保持未提交，未推送、发布或安装到个人 Tabby。

## 已实现行为

| 模式 | 行为 |
| --- | --- |
| 请求审批 | 未命中有效命令集时展示审批；支持允许一次和允许并记住。 |
| 自动编辑 | 已识别且参数受限的低风险操作免命令审批；高危和未知操作每次审批，命令集不能旁路。 |
| 完全访问 | 免命令审批；客户端、连接、白名单、单命令语法和审计仍检查。 |
| 禁止执行 | 不执行命令，也不展示命令审批。 |

四条原始查询 `docker ps`、`ip -4 rule show`、`uci get openclash.config.en_mode`、`nft list table inet fw4` 已纳入低风险规则。变更动作、未知选项、包装器和绝对程序路径不会继承这些查询家族的宽泛批准。

每个具名客户端、每个 SSH 配置独立维护本地命令集；全局默认集初始为空，默认实时继承，可单独关闭。审批框的记忆只写入当前客户端和目标。编辑器支持新增、编辑、删除、清空、复制、粘贴预览、合并和替换，展示全局/本地来源；精确规则只保存 argv 哈希和程序名，不保存参数原文。

设置页重设计后，清空和导入替换只修改本地规则并保留继承开关；清空全局集不删除本地规则。复制只包含当前草稿规则，不带入继承规则。切换模式保留命令集并使旧请求失效；白名单移除时清除相关客户端连接及命令记忆。旧编辑器不能覆盖较新的批准或撤销。

复制可导出最多 256 条全局与本地有效规则，载荷不含 token、客户端身份或 SSH 连接信息。每客户端本地规则总计及全局默认规则各限 128 条，整个私有凭据文件仍限 64 KiB。合并保留显式导入的本地来源；超过目标容量整体拒绝，不通过悄悄删除继承重复项改变授权语义。

## 兼容

- 旧 `readonly/readwrite` 迁移为请求审批，`full` 保留完全访问，`none` 保持禁用。SSH 摘要失效不自动授予新权限。
- 私有凭据兼容读取 v1/v2，成功保存后升级 v3，不旋转 token。旧插件不能读取 v3，降级前须准备私有状态恢复方案。
- 四个 MCP 工具名和输入不变；结构化输出使用 `approval_mode`、`command_risk` 替代 `operation_tier`、`command_class`，硬编码旧字段的调用方需适配。
- 审批窗口 60 秒，命令请求总预算最多 105 秒；审批后执行采集仍限 45 秒，输出仍限 4096 字节。AI 客户端更短的超时仍可能提前取消。
- 继续限制单命令、512 UTF-8 字节及终端控制字符，不增加 Shell 脚本、管道或重定向执行能力。

独立代码审查发现并推动修复：

1. 记忆保存后读取最新命令版本会吸收并发清空。改为在 setter 发起后、await 前固定本次拥有的版本；六种 microtask 时序回归全部通过。
2. 合并审批在连接保存时取消或配置失效仍可能留下连接记忆。连接持久化增加有效性回调，并对提交与 await 续体之间的失效按自有版本清理。
3. 取消时回滚若在临时文件创建处再次失败，可能留下可在重启后读取的授权。回滚前恢复持久保护标记；故障注入验证重启会拒绝加载该未完成事务。

## 复审修正（2026-11-16）

本轮修正审查确认的两个 P1 与一个 P2，并处理复核补充的“取消后补偿写盘失败”边界：

- 请求级的“允许并记住”先将候选写入持久保护标记覆盖的事务，新增规则尚不发布；命令执行结果成功、请求仍有效后才同步完成标记移除与内存提交。取消或失败时恢复原有本地规则及继承状态，较新的操作者编辑不会被覆盖。若恢复临时文件创建遇到 ENOSPC，已存在的保护标记仍阻止重启加载未完成授权。
- 最后一次异步校验之后的请求有效性检查、零字节标记同步删除与内存提交之间不再存在 await，避免取消落入“已删除唯一标记、需要重新创建但磁盘已满”的窗口。不进行同步整文件写入。
- 动态风险原因和授权范围使用结构化原因码、规则类型及中英文翻译键；命令文字及完整指纹保持原值，语言切换会更新说明。
- 若实际命令已尝试执行而最终记忆提交或终端写入发生异常，返回 `outcome_unknown`，不误报为“未执行”。依然不得自动重试。

已先观察到相应回归失败再验证修复。时序回归现在针对候选写入阶段及 SSH 就绪等待阶段：正式规则发布已位于执行之后，原来的“提交通知后取消”不再是零发送窗口。新增覆盖保留既有规则、六种取消时序、并发清空、操作者替换、ENOSPC、最后异步校验及动态中英文说明。
