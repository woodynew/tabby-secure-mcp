# Secure MCP 设置页重设计

2026-11-16：静态预览已由用户确认样式并验收，本阶段将其接入真实插件。

## 接入范围

- 保留 Tabby 的设置侧栏，在插件内分为服务、客户端、SSH 权限和全局命令集。
- 只展开选中客户端的详情，命令集使用独立编辑视图；输入区在列表之前，保存区保持可见。
- 保留现有客户端身份、配置安全摘要、白名单和版本冲突校验；保存失败保留草稿。
- 未保存离开、切换正在输入的规则、清空和导入替换都有确认；输入聚焦只在真实编辑器 DOM 创建后执行。
- 复制仅包含当前命令集的本地规则；清空和导入替换保留继承开关。继承规则另行只读展示。
- 全局默认仍为空。主动填充才将共享的 15 个只读命令族合并到草稿；去重、保留自定义规则，保存后生效。
- 沿用 Angular 15、现有 Bootstrap/Tabby 控件、主题变量与宿主字体；补齐中英文文案，不增加 UI 依赖。

## 本次实现决策

- 预设清单与命令族校验共用同一份只读定义，避免两份策略分叉；`mkdir`、`touch` 继续保留既有命令族支持，但不在填充清单中。
- 精确命令仍只保存程序名和指纹，编辑时须重新输入完整命令，不恢复或额外保存原始参数。
- 保留真实编辑器的显式“添加到草稿”步骤；保存前若存在未完成输入或导入，提示处理，不悄悄批准输入框内容。
- 确认框使用 Electron/Chromium 原生 `dialog`，继承宿主配色并利用原生焦点约束；不新增弹窗框架。
