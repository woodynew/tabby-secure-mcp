# Secure MCP 设置页交互预览

这是用于确认布局和交互的独立静态原型，尚未接入 Angular 插件。所有客户端、SSH、凭据与服务状态均为模拟数据，只保存在页面内存中；刷新重置。没有网络 API 调用、真实凭据生成或 SSH 执行。

## 打开方式

可直接用浏览器打开本目录的 `index.html`，或在仓库根目录运行：

```sh
rtk proxy python3 -m http.server 4177 --bind 127.0.0.1 --directory docs/prototypes/secure-mcp
```

打开 `http://127.0.0.1:4177/`。本原型不需要安装依赖或构建。

## 评审路径

1. 客户端 → OpenWrt → 编辑命令集：检查独立视图、顶部输入、作用范围和固定保存区。
2. 输入 `pwd` → 添加 → 返回：检查继续编辑、放弃、保存并离开。
3. 全局命令集 → 填充低风险命令：检查空默认、15 条只读预设、重复填充去重、保存前不生效。
4. 返回客户端：检查继承数量、本地与全局去重后的生效数量；关闭一个 SSH 的继承不影响其他连接。
5. 本地编辑器 → 复制本地规则 → 另一个 SSH → 粘贴导入：检查预览、合并、替换和保存。复制不包含继承规则。
6. 切换顶部深色、浅色、自定义配色；用场景选择器检查空状态、10 个客户端与长名称、128 条规则上限。

只读预设为 `pwd`、`whoami`、`id`、`uptime`、`uname`、`ls`、`cat`、`wc`、`docker ps`、`ip rule show`、`ip -4 rule show`、`ip -6 rule show`、`uci get`、`uci -q get`、`nft list table`。不填充 `mkdir` 或 `touch`。只读操作的输出仍可能包含敏感信息。

## 设计依据和后续接入

- 按 ui-ux-pro-max v2.0 的需求分析、设计系统生成、UX 补充和技术栈核对流程收敛设计。检索结果中不适合桌面设置的营销页结构和 Angular Material 22 建议未采用。
- 宿主布局、字体和控件优先；桌面编辑器不额外增加第二层侧栏或抽屉。
- Tabby 主题接口核对基于 `Eugeny/tabby@v1.0.238` 的 `themes.service.ts`、`theme.vars.scss`。本原型的三套变量是演示映射，正式集成必须继承宿主实际样式；不能把本文件里的配色直接固定到插件。
- 正式集成沿用 Angular 15 / ng-bootstrap 和现有存储、权限判断与导入导出接口，不增加 UI 框架。
- `model.js` 仅演示规则形状、数量与大小边界，**不是命令风险分类器**；精确命令文本在原型中不执行、不授权、不生成正式规则哈希。后续接入须使用现有共享命令策略。
- 复制格式专用标识为 `secure-mcp-ui-preview`，只能在本原型之间导入；不会冒充正式审批数据。复制连接配置同样使用显式的无效演示凭据。

## 验证

```sh
rtk proxy node --test docs/prototypes/secure-mcp/model.test.cjs
rtk proxy node --check docs/prototypes/secure-mcp/app.js
```

`browser-check.js` 提供 `checkSecureMcpPreview()`，在新加载的隔离浏览器页面中执行。它覆盖顶部输入聚焦、作用范围可见、草稿保存/取消、清空确认、全局填充与继承、本地复制、跨 SSH 导入、空状态及 128 条边界。

本次已验证：6 项模型测试、34 项浏览器断言；900 / 1200 / 1440px 宽度下三种主题的四个分区无页面水平溢出，编辑输入/作用范围/保存区可见；900×800 下长名称与 10 个客户端可用。三种主题的主要文字和辅助文字相对页面表面的最低对比度均超过 4.5:1。浏览器控制台无错误或警告。主题截图在 `screenshots/`。

独立复核发现的两个草稿丢失边界已通过浏览器重现并修复：切换规则前保护尚未加入草稿的输入；导入替换后清理旧行编辑状态，避免保存时覆盖新规则。两条路径均已加入浏览器回归检查。

尚未验证真实 Tabby 宿主主题、实体键盘中文输入法、系统剪贴板权限和真实 SSH／授权存储。本次不安装、不提交、不发布插件。
