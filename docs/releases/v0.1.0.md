# Tabby Secure MCP v0.1.0

The first public version of Tabby Secure MCP exposes a local MCP endpoint from
the main Tabby window. An MCP client can use selected SSH profiles through the
permissions configured in **Settings → Secure MCP**.

- Create and revoke separate credentials for each client. Client access,
  permissions to connect to an SSH profile, and command approvals are managed
  separately in Tabby.
- List whitelisted profiles, open and close client-owned SSH tabs, and run one
  command at a time under the configured approval mode. Eligible owned tabs can
  be reused for later commands.
- Upload or download a single file through SFTP when separately enabled for
  that client and profile. Transfers support files up to 64 MiB and require a
  new destination path.
- The endpoint binds to IPv4 loopback and uses Streamable HTTP with a bearer
  token. The plugin includes the service in a single npm package.

## Getting started

Search for `tabby-secure-mcp` in Tabby's **Settings → Plugins** once the package
appears in the manager, then restart Tabby. Enable the service and create a
named credential under **Settings → Secure MCP**. Start with a dedicated
low-privilege SSH profile and **Request approval**.

- [Connect an MCP client](https://github.com/woodynew/tabby-secure-mcp/blob/main/docs/configure-mcp-clients.md)
- [Tool arguments, results, and permissions](https://github.com/woodynew/tabby-secure-mcp/blob/main/docs/mcp-api.md)
- [Security boundaries](https://github.com/woodynew/tabby-secure-mcp#security-scope-and-limitations)
- [Security reporting](https://github.com/woodynew/tabby-secure-mcp/security/policy)

Tabby controls the SSH transport and host integration. Use the current Tabby
1.0.238 desktop release as the initial compatibility target. Remote command
execution assumes a POSIX shell. Review the
[dependency findings](https://github.com/woodynew/tabby-secure-mcp/blob/main/docs/security-baseline.md)
when evaluating the plugin.
When Tabby reports an uncertain operation outcome, inspect the SSH tab or
destination before deciding whether to retry.
