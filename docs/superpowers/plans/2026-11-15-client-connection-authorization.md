# 按客户端管理配对与 SSH 连接授权

用户已批准本计划；在已有 `codex/secure-mcp-remediation` 工作区扩展内嵌 HTTP 实现，不覆盖先前未提交改动。

## 约定

- 复用已有自定义命名客户端、独立 token、配对授权时效（下次会话、24 小时、永久、清除）。支持客户端首次连接前手动授权。
- 每个客户端对各个全局白名单 SSH 配置独立选择“使用时询问”或“永久允许”；未预授权时保留弹窗。
- 打开标签页和执行命令均检查客户端连接许可；命令等级仍由原有全局 SSH 设置管理。
- 许可绑定凭据身份和配置安全摘要。改名与修改配对时效保留连接许可；凭据重置清空，撤销删除。旧共享打开许可不自动继承。
- 设置实时显示授权变化和配置摘要失效。撤销后，等待中的旧批准不得恢复许可，也不得打开连接或发送命令。
